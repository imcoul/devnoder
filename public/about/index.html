About DevNoder

v0.1.0 · AGPL-3.0 · by Srvel

A useful browser workbench

DevNoder is built around a local-first project workflow: edit supported text files in the browser, preview browser-runnable content, and export a backup. The product is deliberately honest about boundaries instead of presenting a browser shell as a universal native development environment.

Open source

The source code is available on GitHub. Use the issue tracker for bugs and product questions. DevNoder is published under the GNU Affero General Public License v3.0.

Relationship to Srvel

DevNoder is a standalone product with visible editorial attribution “by Srvel”. The parent company reference is srvel.net; this attribution does not imply shared user accounts or capabilities that are not explicitly provided by the app.
